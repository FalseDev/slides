History of NumPy

Origins of NumPy

  • NumPy is the successor of Numeric, an earlier numerical library for Python.
  • It was developed by Travis Oliphant in 2005 to unify the features of Numeric and another library called Numarray.

Development and Adoption

  • NumPy quickly became the foundation for scientific computing in Python.
  • Its efficient handling of arrays and matrices made it popular in data analysis, machine learning, and scientific research.

History of Pandas

Origins of Pandas

  • Pandas was developed by Wes McKinney in 2008.
  • It was created to address the need for a powerful and flexible tool for data analysis in Python.

Development and Adoption

  • Pandas became the go-to library for data manipulation and analysis, particularly in finance and data science.
  • Its DataFrame structure and intuitive API have made it indispensable for data professionals.

NumPy

What is NumPy?

  • Definition:
    • NumPy stands for Numerical Python.
    • It is a fundamental package for scientific computing with Python.
  • Core Features:
    • Provides support for arrays and matrices, along with a collection of mathematical functions to operate on these data structures.
    • Efficient operations on large datasets.

Why Use NumPy?

  • Performance:
    • NumPy is implemented in C, allowing for fast and efficient computations.
  • Convenience:
    • Easy-to-use syntax and powerful features like broadcasting, which simplifies many operations.
  • Integration:
    • Works well with other libraries like SciPy, Pandas, and Matplotlib.

Basic Concepts

  • Arrays: Central data structure in NumPy. Can be 1D, 2D, or N-Dimensional.
  • Data Types: NumPy arrays have a specific data type, like int, float, or complex.
  • Operations: Element-wise operations, matrix operations, etc.

Creating NumPy Arrays

  • From Lists:
    • import numpy as np
array1 = np.array([1, 2, 3])
  • Using Functions:
    • np.zeros((3,3)) - Creates an array of zeros.
    • np.ones((2,2)) - Creates an array of ones.
    • np.arange(0, 10, 2) - Creates an array with a range of values.

Array Indexing and Slicing

  • Indexing: Access elements using square brackets: array1[0] returns the first element.
  • Slicing: Extract a subset of an array: array1[0:2] returns the first two elements.
  • Advanced Indexing: Boolean indexing, integer array indexing for more complex operations.

Broadcasting

  • Definition: A method that NumPy uses to allow arithmetic operations on arrays of different shapes.
  • Example:
    • a = np.array([1, 2, 3])
b = np.array([4])
result = a + b  # [5, 6, 7]

Applications of NumPy

  • Data Analysis: Used in libraries like Pandas for handling large datasets.
  • Machine Learning: Foundation for machine learning libraries like TensorFlow and PyTorch.
  • Scientific Computing: Numerical simulations, statistical calculations, etc.
  • Image Processing: Efficient manipulation of image data as arrays.

Pandas

What is Pandas?

  • Definition: Pandas is an open-source Python library for data manipulation and analysis.
  • Core Features: Provides data structures like Series and DataFrame for handling and analyzing structured data.
  • Integration: Works seamlessly with other libraries like NumPy, Matplotlib, and SciPy.

Why Use Pandas?

  • Efficiency: Optimized for fast data manipulation with large datasets.
  • Ease of Use: Intuitive syntax for data filtering, grouping, and aggregation.
  • Powerful Functionality: Handles missing data, merges/joining of datasets, and time-series functionality.

Core Data Structures

  • Series: A one-dimensional labeled array capable of holding any data type. Similar to a column in a spreadsheet or a SQL table.
  • DataFrame: A two-dimensional labeled data structure with columns of potentially different types. Can be thought of as a collection of Series objects.

Creating a Pandas Series

  • From a List:
    • import pandas as pd
s = pd.Series([1, 3, 5, 7])
  • From a Dictionary:
    • data = {'a': 1, 'b': 2, 'c': 3}
s = pd.Series(data)

Creating a Pandas DataFrame

  • From a Dictionary:
    • data = {'Name': ['Alice', 'Bob', 'Charlie'], 'Age': [25, 30, 35]}
df = pd.DataFrame(data)
  • From a CSV File:
    • df = pd.read_csv('file.csv')

DataFrame Operations

  • Basic Operations:
    • df.head(): View the first few rows of the DataFrame.
    • df.describe(): Generate descriptive statistics.
  • Indexing and Selecting Data:
    • df['column_name']: Select a single column.
    • df.iloc[0]: Select the first row.
    • df.loc[0, 'column_name']: Select a specific element.

Handling Missing Data

  • Checking for Missing Data:
    • df.isnull(): Detect missing values.
    • df.dropna(): Remove rows with missing values.
  • Filling Missing Data:
    • df.fillna(value): Replace missing values with a specified value.

Merging and Joining Data

  • Concatenation: Use pd.concat() to concatenate DataFrames along rows or columns.
  • Merging: Use pd.merge() to perform database-style joins between DataFrames.
  • Joining: Similar to merging, but uses the index to join DataFrames.

Group By Operations

  • Definition: Splitting the data into groups based on some criteria, applying a function to each group, and then combining the results.
  • Example:
    • df.groupby('column_name').sum()

Applications of Pandas

  • Data Wrangling: Cleaning, transforming, and organizing data.
  • Exploratory Data Analysis: Analyzing data to uncover patterns and insights.
  • Time Series Analysis: Handling and analyzing time-indexed data.
  • Data Visualization: Plotting and visualizing data using integrated plotting methods or libraries like Matplotlib and Seaborn.

Installation

Prerequisites

  • Python Installation:
    • Ensure that Python is installed on your system.
    • Verify installation by running: 
      python --version
    • If not installed, download from python.org and follow the installation instructions.
  • Package Manager:
    • Make sure you have pip, the Python package manager, installed.
    • Check with: 
      pip --version
    • If not installed, follow pip installation guide.

Installing NumPy via pip

  • Command Line Installation: 
    pip install numpy
  • Verification:
    • After installation, verify by importing NumPy in a Python shell: 
      import numpy as np
  print(np.__version__)
    • This should output the installed version of NumPy.

Installing Pandas via pip

  • Command Line Installation: 
    pip install pandas
  • Verification:
    • Verify by importing Pandas in a Python shell: 
      import pandas as pd
  print(pd.__version__)
    • This should output the installed version of Pandas.

Installing via Anaconda (Alternative)

  • Why Anaconda?
    • Anaconda is a distribution of Python and R for scientific computing and data science.
    • It comes pre-packaged with many popular libraries including NumPy and Pandas.
  • Installing Anaconda:
    • Download from anaconda.com and follow installation instructions.
  • Creating an Environment with NumPy and Pandas: 
    conda create -n myenv numpy pandas
  • Activate the environment: 
    conda activate myenv
